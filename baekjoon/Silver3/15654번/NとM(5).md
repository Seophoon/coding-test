# NとM(5) \(15654番\)

### 問題

N個の自然数と自然数Mが与えられたとき、以下の条件を満たす長さがMの数列をすべて求めるプログラムを作成しなさい。 N個の自然数はすべて異なる数である。

<li>N個の自然数の中からM個を選んだ数列</li>
     

### 入力

一行目にNとMが与えられる。 \(1 ≤ M ≤ N ≤ 8\)

二行目にN個の数が与えられる。 入力として与えられる数は10,000より小さいか同じ自然数である。


### 出力

1列に1つずつ問題の条件を満たす数列を出力する。 重複する数列を複数回出力してはならず、各数列は空白で区分して出力しなければならない。

数列は辞書順に増加する順に出力しなければならない。
