# Nと M(2) \(15650番\)

### 問題

自然数NとMが与えられたとき、以下の条件を満たす長さがMの数列をすべて求めるプログラムを作成しなさい。

<li>1からNまで自然数の中から重複なくM個を選んだ数列</li>
<li>●選んだ数列は昇順でなければならない。</li>
     

### 入力

一行目に自然数NとMが与えられる。 \(1 ≤ M ≤ N ≤ 8\)


### 出力

1列に1つずつ問題の条件を満たす数列を出力する。 重複する数列を複数回出力してはならず、各数列は空白で区分して出力しなければならない。

数列は辞書順に増加する順に出力しなければならない。
